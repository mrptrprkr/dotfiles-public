\# Public Dotfiles



Public-safe examples of my development environment configuration.



This repository is intended as a portfolio-friendly reference for how I organise shell configuration, cloud tooling, infrastructure-as-code workflows, and local development settings.



My real machine-specific dotfiles are kept private. This public repository contains sanitised examples only.



\## Focus Areas



\- PowerShell 7

\- Git and GitHub CLI

\- AWS CLI

\- Terraform

\- Docker

\- Linux / WSL

\- VS Code

\- JetBrains IDEs

\- General cloud and infrastructure engineering workflows



\## Security Approach



This repository does not contain:



\- credentials

\- access keys

\- API tokens

\- SSH private keys

\- private hostnames

\- cloud account IDs

\- Terraform state files

\- environment variable files

\- terminal history

\- machine-specific paths



Sensitive and machine-specific configuration is intentionally excluded.
